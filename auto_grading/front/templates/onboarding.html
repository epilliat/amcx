▸ Tutoriel rapide (3 min)
  1. Créer un projet avec le template Examen minimal (ou importer un fichier AMC existant).
  2. Éditer le sujet dans l'onglet Sujet : ajouter des questions QCM (single ou multiples) et des questions ouvertes, régler le barème, le nombre de copies, l'en-tête.
  3. Compiler le PDF via le bouton Compiler (produit sujet/DOC-sujet.pdf + le calage sujet/exam.xy).
  4. Imprimer + faire passer l'examen + scanner. Déposer les PDF scannés dans le dossier projet/ du projet.
  5. Lancer le pipeline de correction (commande CLI), puis relire les copies ambiguës et les identités via le dashboard.
